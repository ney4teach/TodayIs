# Подключение облака GNTD

Расширение работает автономно до подключения сервера. Для публикации нужен один экземпляр Node.js 24 с постоянным диском и HTTPS-адресом. Сервер использует встроенную SQLite. Данные и ключи храните вне папки, которую упаковываете как расширение.

1. Создайте OAuth-приложения в Google Cloud (клиент типа Web application) и Яндекс OAuth (веб-приложение). Для домена `https://sync.example.org` зарегистрируйте соответственно `https://sync.example.org/callback/google` и `https://sync.example.org/callback/yandex`. Разрешения Google — `openid profile`, Яндекс — `login:info`. Для Google в режиме тестирования добавьте тестовые аккаунты.
2. Установите переменные окружения из таблицы на сервере. Запустите `node server/server.mjs` и направьте HTTPS-трафик на порт приложения. По умолчанию сервер слушает `127.0.0.1:8787`. Для локальной проверки допустим `PUBLIC_ORIGIN=http://localhost:8787`.
3. В `cloud-config.js` укажите этот же origin без завершающего слэша. В `host_permissions` файла `manifest.json` добавьте `https://sync.example.org/*` (для локальной проверки — `http://localhost/*`). Перезагрузите расширение. Для публикации собирайте только клиентские файлы, иконки и обои.
4. Откройте настройки панели и войдите. Измените масштаб виджетов и добавьте тему со ссылкой в закладках, затем нажмите «Синхронизировать сейчас». Во втором профиле браузера установите расширение и войдите через того же провайдера с той же учётной записью. Проверьте восстановление и обратное изменение.

| Переменная | Значение |
| --- | --- |
| PUBLIC_ORIGIN | Внешний HTTPS-адрес без пути |
| EXTENSION_IDS | Разрешённые идентификаторы расширения через запятую. Тестовый ID виден на chrome://extensions, для магазина укажите ID опубликованного расширения |
| GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET | Реквизиты Google |
| YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET | Реквизиты Яндекса |
| DB_PATH | Абсолютный путь к файлу SQLite в постоянном каталоге сервера |
| PORT, BIND_ADDRESS | Необязательные настройки прослушивания |

При первом входе сервер получает текущие настройки, включая масштаб виджетов, а также задачи, события, сохранённые города и пользовательские закладки. Дерево закладок читается из браузера, прогноз по текущей геопозиции и кэш цитаты остаются в браузере. Последующие установки загружают облачные данные. Аккаунты Google и Яндекса имеют отдельные профили.

Пока вкладка открыта, изменения отправляются после редактирования. Обновления с других устройств проверяются при открытии, возврате на вкладку и раз в минуту на видимой вкладке. При отсутствии сети изменения хранятся на устройстве до следующей синхронизации. При одновременном изменении одного ключа действует последняя полученная запись. Задачи, события, сохранённые города, темы и плитки закладок передаются по отдельным ключам. Выход возвращает прежний профиль браузера. Через 90 дней требуется повторный вход.

Проверка сервера с имитацией ответов Google и Яндекса: `node --test server/server.test.mjs`.
