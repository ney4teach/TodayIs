# Today Is

Русскоязычная панель новой вкладки для Chrome. На одном экране можно посмотреть погоду, запустить поиск, открыть подборку сайтов и узнать, что сейчас играет. Из десяти виджетов каждый собирает свою раскладку.

**Manifest V3 · JavaScript, HTML и CSS · Без сборки**

## Установка

1. Скачайте проект через **Code → Download ZIP** и распакуйте его в постоянную папку. Можно также клонировать репозиторий командой `git clone https://github.com/ney4teach/TodayIs.git`.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку, где лежит `manifest.json`.
4. Откройте новую вкладку. Через шестерёнку в нижней панели можно выбрать тему, обои и виджеты.

## На новой вкладке

| Виджет | Что умеет |
| --- | --- |
| Приветствие | Обращается по имени или псевдониму и учитывает время суток. |
| Часы | Показывают цифровой или аналоговый циферблат, часовые пояса и кольцо активности на сайтах за последние 24 часа. |
| Погода | Показывает погоду по геопозиции и в сохранённых городах. Нажмите на карточку, чтобы открыть прогноз. |
| Закладки | Объединяют плитки сайтов по категориям или показывают закладки браузера. |
| Поиск | Отправляет запрос в Google, Яндекс или DuckDuckGo. |
| Календарь | Позволяет выбрать дату и добавить событие. |
| Задачи | Поддерживают отметку выполнения и редактирование текста двойным щелчком. |
| Музыка | Воспроизводит аудио по ссылке. На Windows может показывать обложку и управлять системными медиасеансами. |
| Цитата | Обновляется раз в сутки. |
| Система | Показывает число логических процессоров. Расход памяти доступен на ChromeOS, загрузка CPU отображается прочерком. |

Включите **режим управления** в нижней панели. Перетащите карточку на другую для обмена местами или потяните за нижний правый угол для изменения размера. Скрытые карточки можно вернуть в **Настройки → Виджеты**.

## Дополнительные возможности

**Системная музыка на Windows.** После установки расширения запустите `media-host\install.cmd` из той же папки. Установщик собирает локальный компонент и регистрирует его для текущего пользователя. Откройте новую вкладку и включите воспроизведение в приложении, которое передаёт медиасеанс Windows. Набор кнопок и доступность перемотки зависят от плеера.

Кнопка «Включить Яндекс Музыку» открывает установленное приложение Windows и пытается продолжить последний трек. При активном плеере запуск доступен в списке источников. Если приложение не восстановило очередь, выберите трек в нём. После обновления запустите `media-host\install.cmd` повторно.


**Облачный профиль.** В разделе **Настройки → Аккаунт** доступен вход через Яндекс ID. Для собственного сервера понадобятся Node.js 24, SQLite и настройки OAuth. [Инструкция по развёртыванию и синхронизации](server/README.md)

## Разработка

| Где искать | Что находится |
| --- | --- |
| `manifest.json`, `newtab.html` | Разрешения, подключение скриптов и точка входа новой вкладки |
| `newtab.js`, `newtab.css` | Сетка, состояние, настройки, встроенные виджеты и стили |
| `activity-worker.js`, `bookmarks.js`, `weather.js` | Учёт активности, закладки и погода |
| `system-music.js`, `media-host/` | Музыкальный виджет и компонент для Windows |
| `cloud.js`, `cloud-config.js`, `server/` | Клиент синхронизации, адрес сервиса, сервер и тесты |
| `icons/`, `wallpapers/` | Локальные SVG-ресурсы |

Из корня репозитория запустите тесты синхронизации:

```sh
node --test server/client.test.mjs server/server.test.mjs
```

Для проверки интерфейса перезагрузите расширение на `chrome://extensions` и откройте новую вкладку. Распределение ответственности между чатами проекта описано в [AGENTS.md](AGENTS.md).
